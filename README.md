# Расписание СПбГУ → календарь айфона

Каждые 3 часа GitHub сам скачивает расписание группы с timetable.spbu.ru
(ту же Excel-выгрузку, что и кнопка на сайте) и обновляет файл `schedule.ics`.
Айфон подписан на этот файл и подтягивает изменения сам.

- Группа и название календаря — в `config.json` (`group_id` — число из ссылки на группу).
- В календаре: 4 недели назад и 10 недель вперёд.
- Обновить вручную: вкладка **Actions** → «Обновить расписание» → **Run workflow**.
